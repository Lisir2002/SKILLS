# de-ai-flavor · 去 AI 味

把 AI 生成的**中文**文本改写得像真人写的：先注入观点、细节与节奏，再清除模板腔、套话、机械句式（三点排比/自问自答/平行否定等结构标志），最后自审 + 量化验证，同时保留全部事实与意图。

> 合规说明：本技能用于优化你自己创作的文本。不用于将 AI 代写/抄袭伪装成原创，不隐瞒学校/期刊要求的 AI 使用披露。

## 什么时候用

- 你说"去 AI 味 / 去 AI 痕迹 / 降 AI 率 / 更像人写的 / AI 味太重"；
- 你粘贴一段 AI 生成的文字，想让它读起来自然；
- 检测工具提示 AI 率偏高，需要改写降率。

## 安装

将本技能目录放入 AI 工具的 skills 目录：

```bash
# Trae / Claude Code 风格
mkdir -p <你的skills目录>/de-ai-flavor
# 把本目录内容（SKILL.md、scripts/、references/）复制进去即可
```

## 用法

在对话中直接触发，例如：

> 这段文字去 AI 味：`<粘贴你的文本>`

或：

> 帮我改得像人写的，这是我的原文：`<粘贴>`

### 可选：提供你的写作样本

想让改写贴合你自己的风格，可附上 2-3 段你自己的文字作为"人味样本"，技能会模仿你的节奏与口头禅。

### 可选：量化验证（脚本）

技能包附带一个纯标准库 Python 脚本，可在改写前后对比"AI 味评分"：

```bash
python3 scripts/scan_ai_flavor.py --text "你的文本"
```

输出为 JSON，包含：命中标志词（词级）、结构标志（三点排比/自问自答/平行否定/破折号等）、语法标志（翻译腔/名物化/"的"字连珠/介词框架/连接词过密）、标点标志（分号滥用/冒号过多/一逗到底/语气标点缺失）、句子数量、平均句长、句子长度方差（突发度代理）、AI 味评分（0-100）与判定。

## 工作方式（三遍式）

1. **Voice** — 先给文本注入人味：具体数据、观点立场、第一人称、口语过渡、节奏变化；
2. **Tells** — 再清除 AI 标志，四层排查：结构级（平行否定/三点排比/自问自答/破折号滥用）> 语法级（翻译腔/名物化/"的"字连珠/介词框架/连接词过密）> 标点级（分号/冒号/一逗到底/语气标点）> 词级（套话/模板腔）；
3. **Audit** — 自审"哪里还会露馅"再改一轮，并跑脚本量化对比。

学术论文场景会自动锁定专业术语、穿插个人专属细节；自媒体/职场场景有不同的语气档位。

## 依赖

- `python3`（可选，仅脚本需要）；脚本零第三方依赖，可离线运行。

## 示例

**原文（AI 味重）**
> 综上所述，人工智能在现代社会扮演着至关重要的角色。首先，它能够显著提升工作效率；其次，它可以赋能各个行业实现数字化转型；最后，我们必须重视由此带来的挑战。

**改写后（人味）**
> 说真的，AI 已经悄悄钻进我们每天的工作里了。以前要三个小时整理的报表，现在十分钟出结果。但它也带来麻烦——同事开始担心岗位，学校开始防抄袭。技术是容易的部分，难的是我们怎么跟它相处。
