# 中文"去 AI 味"执行指令集（AI 可执行版）

> 本文件是 `de-ai-flavor` 技能的**唯一规则源**，供 AI 读取并严格执行，不是给人看的百科。
> 当你被触发去 AI 味任务时：**先读本文件，再执行改写**。
> 每条规则格式固定：`触发条件 → 执行动作 → 示例`。命中即处理，不要"酌情"、不要"看情况"。

## 0. 执行协议（必读）

1. **规则优先级**：本文件 > SKILL.md 流程 > 你的默认写作习惯。
2. **四类规则必须全部执行**：A 强制删除 → B 结构重构 → C 语法改写 → D 标点修正；E 人味注入为主动添加项。
3. **判定原则**：单个词不是罪证，**密度**才是。但 A 类词出现即删（无需计数）。
4. **信息红线**：所有改写不得删除事实、数字、专名、专业术语。拿不准就保留。
5. **交付前**：必须完成第 6 节自查清单，全部打勾后才能输出。

## 1. A 类 · 强制删除清单（出现即删）

以下词/短语命中即删。若整句只剩这些词，直接重写该句。

| # | 删除项 | 动作 | 示例（前 → 后） |
|---|--------|------|------------------|
| A1 | 综上所述 / 总而言之 / 总的来说 / 总之 | 整词删除，用具体事实收束 | "综上所述，方案可行" → "方案跑了三轮测试，都通过了" |
| A2 | 值得注意的是 / 值得一提的是 / 不难发现 | 删除，直接陈述事实 | "值得注意的是，成本降了" → "成本降了" |
| A3 | 毋庸置疑 / 不言而喻 / 众所周知 / 显而易见 | 删除 | "毋庸置疑，他很努力" → "他确实很努力" |
| A4 | 在当今时代 / 在当今社会 / 随着科技的不断发展 / 在这个数字化时代 | 删除，直接进主题 | "在当今时代，AI 很重要" → "AI 很重要" |
| A5 | 让我们来…… / 让我们深入探讨 | 删"让我们"，直接说内容 | "让我们来看看数据" → "看数据" |
| A6 | 扮演着至关重要的角色 / 发挥着重要作用 / 具有重要意义 / 起着关键作用 | 换成具体动作 | "该功能发挥着重要作用" → "该功能直接决定登录成功率" |
| A7 | 首先 / 其次 / 第三 / 最后（作模板序数） | 用真实逻辑（时间/因果/递进）替代，或直接并列 | "首先，收集数据；其次，分析" → "先收集数据，再分析" |
| A8 | 不容忽视 / 不可忽视 / 举足轻重 | 删除或改具体描述 | "其影响不容忽视" → "它影响到了每月的报表" |

## 2. B 类 · 结构模式重构（命中即重构）

| # | 检测 | 执行动作 | 示例 |
|---|------|----------|------|
| B1 | 平行否定：`不是 X，而是 Y` / `并非 X，而是 Y` / `不是……而是……` | 只留 Y，删对比 | "这不是工具，而是平台" → "这是平台" |
| B2 | 三点排比：恰好 3 个并列项（顿号或"要 A、要 B、要 C"） | 改成 2 项或 4 项，或拆成句 | "快、稳、安全" → "快而且稳" |
| B3 | 自问自答：`那么问题来了？答案是……` | 删问句，直接给答案 | "问题来了？答案是加密" → "加密是答案" |
| B4 | 破折号滥用：全文 `——` ≥ 2 处 | 第 2 处起改为逗号/句号/括号 | "它——对，就是它——改变了" → "它（对，就是它）改变了" |
| B5 | 镜像结构：`一是……二是……` / 前后句同句式 | 换一种句式，两句不平行 | 见右侧：拆成因果或让步 |
| B6 | 段首概括句：每段首句为"XX 很重要/XX 是什么" | 换成场景、问题或例子开头 | "流程很重要" → "上周因为流程漏了一步，整个发布推迟了两天" |
| B7 | 段尾总结腔：段尾出现"由此可见/综上" | 删除，以具体事实结尾 | 见 A1 |

## 3. C 类 · 语法改写（中文翻译腔/名物化）

| # | 检测 | 执行动作 | 示例 |
|---|------|----------|------|
| C1 | 名物化/虚化动词：`对 X 进行 Y` / `加以` / `予以` | 直接动词化 | "对数据进行分析" → "分析数据"；"加以解决" → "解决" |
| C2 | "的"字连珠：连续 ≥3 个"X 的"定语链 | 拆成短句，或改逗号/破折号 | "一个经过长期验证的、高度可靠的、跨平台的方法" → "这个方法验证过很多年，很可靠，还跨平台" |
| C3 | 介词框架：`对于……来说` / `在……方面` / `通过……的方式` / `随着……的发展` / `在……的背景下` | 直接陈述主体+动作 | "对于用户来说，这功能重要" → "用户很看重这功能"；"通过测试的方式" → "靠测试" |
| C4 | 连接词过密：句句"因此/所以/然而/同时/此外" | 每 3 句最多保留 1 个连接词，其余删 | "因此成本降了。所以利润涨了。然而竞争也来了" → "成本降了，利润跟着涨。但竞争也来了" |
| C5 | 被动句堆叠：连续 ≥3 个"被"字句 | 主/被动交替 | "数据被收集、被分析、被展示" → "收集数据，做分析，把结果展示出来" |

## 4. D 类 · 标点修正（AI 标点太规范）

| # | 检测 | 执行动作 | 示例 |
|---|------|----------|------|
| D1 | 分号滥用：`；` ≥ 2 处 | 拆成独立句，或改逗号/句号 | "A；B；C" → "A。B。C" |
| D2 | 冒号过多：`：` ≥ 3 处（尤其"：首先""：一、"） | 改普通叙述 | "三个步骤：一、备料；二、加工" → "分三步，先备料再加工" |
| D3 | 一逗到底：单句内 `，` ≥ 4 个 | 断成 2-3 句 | 见右侧：把长句按意群切断 |
| D4 | 语气标点缺失：全文 ≥150 字且无 `？` `！` | 在合适处补 1-2 个（反问/感叹） | "这条路没有标准答案" → "这条路，哪有标准答案？" |
| D5 | 引号缺失：全文无引号 | 在强调/引用处加引号 | "所谓的降本增效" → 保留并加引号"降本增效" |

**人的标点（可选，按场景）**：省略号（`……算了不说了`）、括号插话（`（对，就是它）`）。自媒体可加，学术/职场不加。

## 5. E 类 · 人味注入（主动添加）

改写时**主动**加入以下任一项（每 2-3 句至少 1 处，不要堆）：

| # | 注入项 | 示例 |
|---|--------|------|
| E1 | 具体数字/时间/地点 | "加载从 4.2s 降到 1.6s" |
| E2 | 第一人称经验 | "我试过""上次我们" |
| E3 | 观点立场 | "说实话，这条我之前也不信" |
| E4 | 口语过渡 | "其实""说白了""问题在于" |
| E5 | 混合情绪 | "上线了，但成本也翻倍，值不值我还没底" |
| E6 | 节奏变化 | 短句 + 长句交错，允许"一句话段" |

**禁止**：不要为了像人而乱用网络流行语、不要制造虚假经历、不要夸大情绪。

## 6. 交付前自查清单（必做，逐项打勾）

改完必须逐项确认，全部 ✓ 才输出：

- [ ] 已删除全部 A 类词（A1-A8）
- [ ] 已重构全部 B 类结构（B1-B7），无三点排比、无平行否定、无自问自答
- [ ] 已改写全部 C 类语法（C1-C5），无"对……进行"、无"的"字连珠、连接词不密
- [ ] 已修正 D 类标点（D1-D5）：分号 ≤1、冒号 ≤2、无长句一逗到底
- [ ] 全文 ≥1 处 E 类人味（数字/人称/观点/口语/情绪/节奏）
- [ ] 已保留全部事实、数字、专名、专业术语（信息零损失）
- [ ] 全文至多 1 个段落以 ≤8 字短句结尾
- [ ] 结尾不是"总之+号召"式总结
- [ ] 通读一遍，没有一句像机器写的（若有，再改）

## 附：场景档位（仅在用户指定场景时应用）

- **学术论文**：用【】锁定专业术语不得改动；每 ~200 字插入 1 处本人课题专属细节（样本量/设备/调研时间/批判性评述）；不用口语词；主/被动交替。
- **自媒体/公众号**：可用省略号/括号插话；保留"钩子-展开-收尾"但删模板过渡；结尾用反问或干脆收束。
- **职场/邮件**：克制口语化；用具体数据支撑结论；不滥用感叹号。

## 附：脚本验证命令

改写前后各跑一次对比（确认 `ai_flavor_score` 下降、`syntax_markers`/`punctuation_markers`/`structural_markers` 清零）：

```bash
python3 scripts/scan_ai_flavor.py --text "<原文>"
python3 scripts/scan_ai_flavor.py --text "<改写稿>"
```

> 设计依据：腾讯朱雀（困惑度+突发性）、GPTZero 三重指标、Wikipedia "Signs of AI writing"、RUC 新闻坊标点实测（AI 更爱冒号/分号，真人更爱引号，破折号仅滥用是问题）、社区 humanize 技能与学术诚信规范。本文件随社区研究持续更新，规则与 `scripts/scan_ai_flavor.py` 检测逻辑保持一致。
