# 创新技法库（12+ 技法 + 触发场景 + 示例）

> 供 creative-mind 技能 Step 2 发散时选用。每种技法给：一句话原理、触发场景、
> 一个可套用的提问模板、一个示例。**技法不是答案，是岔路口**——在其上继续想象。

## 1. SCAMPER（奔驰法）

对现有事物逐项做七种操作，是"改造已有"最系统的技法。

- **原理**：创造力常来自对已有方案的小幅扰动，七种扰动覆盖不同方向。
- **触发**：已有明确对象要改良时（产品/流程/文案/活动）。
- **提问模板**：替换？组合？调整？放大/缩小？换用？消除？反转？
- **示例**：对"办公椅"——S 把椅背换成吊床布（午休椅）；C 和健身器材组合（办公健
  身椅）；E 去掉轮子和扶手（极简凳）；R 让人倒着坐（防久坐姿势矫正）。

## 2. 跨域融合（Combinatorial Creativity）

把两个**不相关**领域强行组合，让一个领域的机制迁移到另一个。

- **原理**：创新 = 把距离远的元素建立新连接；领域越远，组合越可能罕见。
- **触发**：要"全新品类 / 没人做过"时。
- **提问模板**：把「主题」与「随机领域 A」结合：A 的机制能否迁移过来？
- **示例**：让"蜂群分布式决策"迁移到"城市停车"→ 车位像信息素一样自我组织标记、
  车辆像工蜂一样绕行避让，形成无中心调度。

## 3. 反事实思维（Counterfactual）

假设历史/条件在某一点分岔，推演涟漪效应。

- **原理**：把"理所当然"的前提拿掉，才能看见它本来的贡献与代价。
- **触发**：要"颠覆性 / 重新想象"时；或现有方案太顺理成章时。
- **提问模板**：假设某关键前提不存在/被改变，世界会如何演化？
- **示例**：如果"键盘的 QWERTY 布局"从未出现，输入法会怎么设计？→ 或许早就有
  按字母频率优化的布局，而不是把常用键放在难按的位置。

## 4. 第一性原理（First Principles）

丢弃所有现有方案与假设，从最底层的约束重新搭建。

- **原理**：类比只能让你接近别人的成果，从原理出发才能造出别人没造过的东西。
- **触发**：要"根本性突破 / 价格性能指数级改善"时。
- **提问模板**：剥掉包装后，用户真正想要的核心价值是什么？最底层的约束是什么？
  从零开始先造哪一块？
- **示例**：SpaceX 不假设"火箭必须按行业价制造"，而是从"材料成本"出发，
  得出"火箭可回收复用"这一此前被行业当作不可能的结论。

## 5. 反转（Reversal）

把关键属性、关系、流程、评价标准倒过来。

- **原理**：反转强制你离开默认方向，往往暴露被忽略的另一面。
- **触发**：方案平淡无奇时。
- **提问模板**：把目标/关系/流程/评价反转，会是什么样？
- **示例**：健身 App 反转"目标"→ 不追求"练得多"，而追求"休息得好"，
  变成"恢复优先"的 App；把"缺点"反转成卖点（"充电慢"→"慢充更护电池"）。

## 6. 极端化（Extreme）

把某个维度推到极端（成本→0、速度→无限、尺寸→极小/极大、次数→一次/无数）。

- **原理**：极端值暴露隐藏约束，也常引向"全有全无"的新形态。
- **触发**：要"颠覆性体验 / 破局"时。
- **提问模板**：如果成本为零 / 瞬间可得 / 只能用一次……会怎么设计？
- **示例**：如果咖啡"只能喝一次就再买不到"，你会怎么设计？→ 变成纪念品、
  故事载体、一次性的仪式体验，而不是日常消耗品。

## 7. 类比迁移（Analogy）

借用一个**冷门领域**的机制，映射到本领域。

- **原理**：冷门领域没有本领域的"思维定式"，机制新鲜度最高。
- **触发**：本领域解法枯竭、想要跳出时。
- **提问模板**：借用「冷门领域」（其机制）映射到本主题会产生什么？
- **示例**：把"苔藓在贫瘠岩面上先着床、再逐步丰化"迁移到"新社区冷启动"→
  先服务 1% 的"着床用户"，给他们极致支持，再让生态自然长出来。

## 8. 随机刺激（Random Stimuli）

用随机词/图像作为种子，强扭成相关方案（先接受荒谬，再找逻辑）。

- **原理**：随机词打破联想惯性，逼你建立原本不会建立的连接。
- **触发**：脑洞枯竭、需要"意外"时。
- **提问模板**：用随机种子『X』强扭成本主题相关的点子。
- **示例**：种子"回声"→ 健身房镜子不只显示动作，还"回放"你三年前的姿态，
  形成"身体的时间回声"。

## 9. 口述采样（Verbalized Sampling）

先列出 5 个候选方向及它们的"被选中概率"，再从中选/杂交。

- **原理**：直接取峰值=套路；先展开分布再选择，才能避开最安全答案。
- **触发**：任何发散开始前，可作前置步骤。
- **提问模板**：列出 5 个可能的候选方向及概率，再挑 2 个杂交。
- **示例**：给"社区咖啡店"列 5 方向（自习室/宠物友好/夜间酒馆/旧书主题/无人自助）
  → 选"旧书 + 夜间酒馆"杂交出"深夜书房"。

## 10. 主动反对（Devil's Advocate / Red-team）

先产出一个方案，再用"挑剔读者"身份攻击它，找到 ≥3 处套路或漏洞，逐处改写。

- **原理**：模型"评估"往往比"生成"更准；反对能暴露舒适区的自洽。
- **触发**：已有初稿、要打磨到"不像套路"时。
- **提问模板**：以最挑剔的读者身份，列出本方案 3 处"还是套路/无新意"，并逐处改写
  （给出改写前后对比）。
- **示例**：初稿"全面提升用户体验" → red-team 指出"全面"是空话 → 改写为
  "把下单按钮从 3 次点击降到 1 次"。

## 11. 约束设计（Anti-goals）

主动排除显而易见的方案，或给任务加反目标。

- **原理**：约束（尤其负面约束）会逼出非显然路径——"不许用 X，你怎么做？"
- **触发**：常规方案太容易想到时。
- **提问模板**：不许用「显然方案 X」，你还能怎么做？
- **示例**："海水淡化不用热、不用膜" → 逼出高压反渗透之外的路：利用潮汐压差、
  电解、甚至植物蒸腾，思路立刻变宽。

## 12. 角色视角切换（Role Shifting / Persona）

用不同角色的视角审视同一问题（婴儿/工程师/外星人/经济学家/诗人……）。

- **原理**：不同角色有不同的"理所当然"，视角即过滤器。
- **触发**：想法过于单一视角时。
- **提问模板**：从「角色 X」的视角看，这个问题真正重要的是什么？
- **示例**：让"经济学家"看共享单车（定价/押金/外部性），让"诗人"看（城市里
  的移动自由），让"5 岁小孩"看（会自己走的玩具车）→ 三个完全不同方向。

## 13. 知识边界探索（Fable 式：未知优先）

先画"已知领域地图"，再刻意把镜头推向**边界之外**的未知区。

- **原理**：创造力发生在已知知识的边界地带；大多数人停留在已知区内微调。
- **触发**：要做"别人没做过"的研究/方案时。
- **提问模板**：这个问题我们已知什么？边界在哪？边界之外最有可能藏着什么？
- **示例**：已知"用户调研-设计-开发-上线"，边界之外可能是"让用户参与定义需求
  本身"——UGC 式的共创产品。

---

## 如何选用

- **要改造已有** → SCAMPER / 反转 / 约束设计
- **要全新品类** → 跨域融合 / 第一性原理 / 反事实
- **要突破瓶颈** → 极端化 / 类比迁移 / 知识边界探索
- **要打磨去套路** → 口述采样 / 主动反对 / 角色视角
- **脑洞枯竭** → 随机刺激 / 角色视角
