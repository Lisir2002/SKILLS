# 四步工作流原理：为什么模型会"固化"，以及如何破

> 本文解释 creative-mind 技能背后的原理，帮助模型理解"为什么要这么做"，
> 从而在未知场景也能正确泛化。规则会过时，道理不会。

## 一、问题根源：模式坍缩（Mode Collapse）

大语言模型在开放任务中有一个系统性倾向：**持续输出高度相似、符合统计平均的"安全答案"**。
研究界称之为"人工蜂群思维效应 / 模式坍缩"——明明同一个问题问一百次，得到的却是同一个
"最典型"的答案。

### 根因不是算法，是人类的"典型性偏见"

人类标注者偏好数据时，天然更青睐熟悉、流畅、可预测的文本。这个"典型性偏见"被训练
过程放大：

- 奖励函数把概率分布**尖锐化**到最符合刻板印象的输出上；
- 模型学会的不是"探索可能性的边界"，而是"全力迎合人类最舒适的认知区"；
- 结果：模型在创意任务里，总是从所有可能答案里取**概率最高那一个**。

### 这对"创造力"意味着什么

当你直接问模型"给个新点子"，它取的是**分布峰值**——不是新的，是最常见的。
所以"直接提问"天然产出套路。破解思路只有一条：

> **不要先问"答案是什么"，先问"有哪些可能的答案"。**

## 二、破解机制：口述采样（Verbalized Sampling）

把提问从"取峰值"改成"先展开分布、再从中选择"：

- 旧方式：`给智能水杯想个卖点` → 直接吐"智能温控、喝水提醒、APP 连接"（峰值）。
- 新方式：`先列出 5 个可能的卖点方向及概率，再从中选` → 模型被迫探索低概率、
  但更新颖的路径，然后才收敛。

本技能的工作流就是把这条口诀固化为强制步骤。

## 三、四步引擎详解

### Step 1 · 破固化（Detach）：先暴露默认路径

模型的默认输出是可预测的。**先把它说出来**，标记为"不直抄的模板"，默认路径就被
"禁用了"，后续发散必须找别的路。这利用的是**反例约束**：明确了"不要什么"，
模型才不容易滑回舒适区。

### Step 2 · 发散（Diverge）：用技法强制岔路

发散性思维（Divergent Thinking）是创造力的核心成分。单个技法容易失效，所以引擎
内置多技法并用（SCAMPER / 跨域融合 / 反事实 / 第一性原理 / 反转 / 极端化 / 类比 /
随机刺激 / 口述采样），每条岔路都要求**角度不同**。核心约束：**≥3 个候选**，
避免"同一观点的三种措辞"。

### Step 3 · 收敛（Converge）：杂交 + 三维筛选

创造性常发生在"把两个不相关的东西强行杂交"的交叉处。筛选用三轴：

- **新颖度**：真的少见吗？（不是"少见的措辞"，而是"少见的组合/角度"）
- **可行性**：能落地吗？（为创新而怪的方案不是创新）
- **价值**：值得吗？（对谁有价值、解决什么）

给方案命名是强制的：**命名迫使你把模糊念头聚焦成一个明确的实体**。

### Step 4 · 验新（Verify）：两层去套路

1. **自批判 red-team**：模型"评估"往往比"生成"更准。让它以挑剔读者身份
   找出 ≥3 处"还是套路/无新意"，并**实际改写**（要求改写前后对比，防止走过场）。
2. **机械检测**：用 stereotype_scan.py 量化剩余套路。人对自己的套路有"视盲区"，
   机械扫描（负面词库 + 结构模式）补上这一盲区，且结果可复现、可对比。

## 四、为什么这套能"造出属于自己的新东西"

模型的知识储备 = 训练数据 + 上下文。所谓"造新"，不是无中生有，而是**把储备里
距离很远的元素，用前所未见的组合方式拼接起来**（组合式创造 Combinatorial
Creativity）。四步引擎做的正是：

1. 破固化 → 禁用"最近的邻居"（最常见组合）；
2. 发散 → 把搜索半径推到"远距离元素"；
3. 收敛 → 在远距离元素之间建立新的连接；
4. 验新 → 确认这个连接真的罕见、且成立。

所以它产出的是**基于知识储备的新连接**——"属于自己的新思想"，而不是凭空捏造，
也不是背诵现成答案。

## 五、参考依据

- Mode collapse / artificial hivemind effect 研究（LLM 发散思维退化）
- Verbalized Sampling（口述采样：先列分布再选择，推理期解锁多样性）
- Divergent Association Task（DAT）、Alternative Uses Test（AUT）等发散思维评估
- SCAMPER、TRIZ 等经典创新方法
- First-principles reasoning（第一性原理）、Counterfactual thinking（反事实思维）
- 负面风格指南 / 陈词滥调烧除（Cliché Burndown）等去套路技巧
