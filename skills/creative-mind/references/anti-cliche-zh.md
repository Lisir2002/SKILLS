# AI 套路 / 陈词滥调负面清单

> 这是 creative-mind 的"负面风格指南"：列出模型最常用的套路词、句式与结构，
> 供（1）模型写作时主动避开，（2）stereotype_scan.py 机械检测时命中。
> 用途是**去套路**，不是禁止使用——个别词在特定语境下完全正常，这里抓的是
> "密集出现"与"作为空话填充"的用法。

## 一、词级：高频套话 / 空话

### 1. 万能连接词（让句子"看似有条理"实则空转）

```
综上所述 / 总而言之 / 总的来说 / 由此可见 / 在此基础上 / 与此同时 /
值得注意的是 / 需要注意的是 / 不可否认 / 毋庸置疑 / 显而易见 / 众所周知
```

**为何是套路**：它们不增加信息，只制造"我在总结/我在强调"的假动作。真正有力的
总结是直接给出新信息或数字。

### 2. 空泛修饰词（安全的形容词，谁都能说）

```
极大地 / 显著地 / 有效地 / 深入地 / 全面地 / 极大地推动了 / 不断提升 /
日益 / 越来越
```

**为何是套路**：不给出量级与对象。改成"下单转化率 +12%"就比"显著提升"有力一百倍。

### 3. 烂大街的"商业黑话"（过度使用显得空洞）

```
赋能 / 抓手 / 闭环 / 痛点 / 链路 / 颗粒度 / 方法论 / 底层逻辑 / 顶层设计 /
降维打击 / 破圈 / 出圈 / 重构 / 颠覆 / 跃迁 / 升维 / 范式转移 / 穿越周期 /
第二曲线 / 飞轮 / 护城河 / 打通 / 落地 / 场景化
```

**为何是套路**：这些词本身没被定义，读者无法从中得到具体画面。"赋能"到底做了什么？
说动作，别说黑话。

### 4. 陈词滥调隐喻（被用滥的"诗意"）

```
点亮 / 照亮 / 唤醒 / 种子 / 桥梁 / 灯塔 / 窗户 / 钥匙 / 翅膀 / 梦想
```

**为何是套路**：意象本身没问题，问题是它们太常见，读者已自动跳过。"给梦想插上
翅膀"没人读得进去。

### 5. 英文 AI 高频词（生硬/模板感）

```
delve / tapestry / moreover / furthermore / it is important to note /
in conclusion / embark on / pivotal / robust / seamless / leveraging
```

## 二、结构级：模板句式

### 1. 三点排比（最明显的 AI 指纹）

```
它不仅……，而且……，更……。
我们要做到 X，要做到 Y，要做到 Z。
```
三个结构相同的分句并列，读起来工整但空洞。

### 2. 自问自答（假装互动）

```
为什么要这么做？因为……
是否值得？答案是肯定的。
```

### 3. 平行否定（"不是…而是…"滥用）

```
这不是 X，而是 Y。
我们不再追求……，而是要……
```

### 4. 破折号滥用（用破折号强行插入解释）

```
它——这个产品——正是……
```

### 5. 标题冒号（每句标题都是"主题：卖点"）

```
智能水杯：重新定义喝水
```
偶尔用没问题；通篇都是这种标题就是模板。

### 6. "的"字连珠（名词堆砌）

```
一个基于人工智能的面向企业用户的智能数据分析解决方案的深度优化的……
```

### 7. 连接词过密（因此/然而/同时/其次 高频堆叠）

```
因此，我们需要……同时，……然而，……其次，……
```

## 三、高风险组合（命中任意一个强烈提示回炉）

- 段落开头出现"综上所述"或"总而言之"；
- "值得注意的是 / 需要注意的是" 出现在开头做强调；
- 三个空泛修饰词（"极大地、全面地、深入地"）出现在同一句；
- 一套黑话连发（"以底层逻辑赋能闭环，破圈重构链路"）。

## 四、改写方向（怎么把套路句改活）

| 套路 | 改写原则 | 示例 |
|------|----------|------|
| 空泛修饰词 | 换成具体数字/事实 | "显著提升体验"→"下单步骤从 3 步变 1 步" |
| 万能连接词 | 删掉，直接说下一句 | "综上所述，方案可行"→"已跑通 3 个试点" |
| 黑话 | 说动作，定义名词 | "赋能业务"→"帮业务把报表产出时间从 2 天降到 2 小时" |
| 三点排比 | 打散结构，长短句交错 | 保留最强的一个，删掉其余两个 |
| 陈词隐喻 | 换成具体、少见的意象或直接陈述 | "点亮希望"→"把路灯换成感应式，晚归的人不再摸黑" |
| 自问自答 | 直接给答案或结论 | 删掉问句，直接说"因为……" |

## 五、注意：反套路 ≠ 猎奇

去套路是为了**信息密度与真诚**，不是为怪而怪。避开的是"空话与模板"，不是
"清晰的表达"。一句朴素、具体、有信息的话，永远好过一句华丽但空洞的话。
