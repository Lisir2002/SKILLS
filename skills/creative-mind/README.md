# creative-mind · 通用创新引擎

让模型**在自己已有的知识储备上造出属于自己的新东西**——不固化思想、会自己造东西、有自己的新思想、跳出固定思维、真的会创造。核心是破解大模型的"模式坍缩"：默认输出概率最高、最安全、最套路的答案，本技能用四步引擎强制跳出典型答案。

> 定位：通用创新引擎。任何"要有新想法"的场景都适用——文案、点子、产品方案、架构设计、故事、标题、策划，一视同仁。

## 什么时候用

- 你说"想个新点子 / 要创新 / 脑洞一下 / 给我点灵感 / 想出个不一样的"；
- 你说"跳出思维定式 / 打破常规 / 别按套路来 / 不要模板化 / 要原创 / 与众不同 / 重新发明";
- 你嫌输出"太套路 / 太模板 / 像 AI 写的 / 没新意"，想重做。

## 安装

将本技能目录放入 AI 工具的 skills 目录：

```bash
# Trae / Claude Code 风格
mkdir -p <你的skills目录>/creative-mind
# 把本目录内容（SKILL.md、scripts/、references/）复制进去即可
```

## 用法

在对话中直接触发，例如：

> 给这个产品想 3 个不一样的营销点子：`<产品描述>`

> 这段文案太套路了，重新写，要有新意：`<粘贴原文>`

### 可选：发散脚手架（脚本）

想让发散更系统、更跳脱，可让模型先跑脚手架：

```bash
python3 scripts/idea_scaffold.py --topic "智能水杯卖点" --domain product --techniques cross_domain,counterfactual,extreme
```

输出一组"岔路口"式启发（跨域种子、SCAMPER 提问、反事实分支、第一性原理拆解），模型在此基础上继续想象出真正的原创方案。

### 可选：固化度检测（脚本）

交付前量化"还剩多少套路"：

```bash
python3 scripts/stereotype_scan.py --text "你的交付内容" --type idea
```

输出 JSON：固化度评分（0-100）、命中的 AI 套路/陈词滥调清单（词级）、结构标志（三点排比/自问自答/平行否定等）、高风险模板命中、判定（低/中/高固化）。评分偏高就回去重想一轮。

## 工作方式（四步引擎）

1. **破固化 Detach** — 先说出"典型答案"并标记为不直抄，绕开默认路径；
2. **发散 Diverge** — 用技法库（SCAMPER/跨域融合/反事实/第一性原理/反转/类比/随机刺激）产出 ≥3 个角度不同的候选，绝不直接给 1 个"最好"的答案；
3. **收敛 Converge** — 挑最不相干的两个候选杂交，用"新颖/可行/价值"三维筛选，给方案命名；
4. **验新 Verify** — red-team 自批判找 ≥3 处套路并改写，跑 stereotype_scan 量化，不达标不交付。

## 示例

**用户**：给智能水杯想 3 个不一样的卖点文案。

- 破固化：典型答案 = "智能温控 / 喝水提醒 / APP 连接"，不直抄；
- 发散：跨域（植物感知口渴→杯身可视化"口渴度"）、反事实（杯会聊天→角色化提醒）、极端化（杯盖变迷你盆栽/香薰座→喝水成仪式）；
- 收敛：杂交"感知+提醒" → 命名「渴感杯」；
- 验新：stereotype_scan 固化度 22，0 高风险模板，red-team 改写后交付。
